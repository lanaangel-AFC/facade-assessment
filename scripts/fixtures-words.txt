# AFC word library — technical terms for dictation in every AFC app.
#
# HOW TO EDIT (on github.com: open this file, click the pencil icon, edit, "Commit changes")
#   One entry per line. Lines starting with # are notes and are ignored.
#
#   A word or phrase on its own line is a term the speech service should expect:
#       sealant
#       backer rod
#
#   "heard => meant" tells the speech service a common mix-up. Anything after a
#   second # is extra context for that mix-up:
#       Fejsa => façade
#       ceiling => sealant    # when talking about joints
#
#   Apps pick up changes within an hour (or straight away from the app's word
#   library status button). Keep to general technical terms — no client details.
